# 手帳

自分専用の手帳アプリです。見た目の基本は Google カレンダーで、そこに「予定ごとの詳しい情報」と「実際の時間の使い方」を書き足せます。

サーバーは持たず、データはすべて使っている端末のブラウザの中に保存されます。

## できること

**カレンダー**

- 月・週・日の表示（Google カレンダーと同じ並び）
- Google カレンダーと同期（取り込み、手帳で作った予定の書き戻し、繰り返し予定）
- 月表示は「特別な予定のみ」に絞れる。毎週の授業やバイトは隠し、友達と遊ぶなどの予定だけを出す
  - 自動の決まり：繰り返しの予定は隠す／テストと締切は必ず出す
  - 種類ごとに「いつも出す・いつも隠す」、予定ごとに「月表示に出す」で上書きできる

**予定のページ**（予定をタップした先）

- リンク（Google ドキュメント、メールなど）
- 資料・PDF、ノート（Samsung Notes から書き出した PDF など）
- 持ち物、提出物（チェックリスト）
- テストなら、試験内容・範囲と結果
- 計画（締切までに、いつ何をやるか）。ステップは同じカレンダーに並ぶ
- 関連する予定（試験に出願日・入金期限をつなげて、すぐ飛べる）
- 種類（勉強・運動・バイトなど）とプロジェクト

**一日の画面**

- 右に予定、左に実績（実際の時間の使い方）
- 予定の「←」を押すと実績にコピー。違った部分だけ、端をつまんで長さを、真ん中をつまんで位置を直す（下の欄で時刻を入力しても直せる）
- 上に、予定と実績の時間を種類別に比べる帯グラフ
- その日の「やること」「持ち物・提出物」「日記」

**時間の使い方**（週）

- 一週間分の実績を横棒の帯グラフで並べる
- 「時間帯」（0〜24時のどこで何をしたか）と「合計」（種類ごとの時間）を切り替え
- 予定と並べて比べる、表で見る
- 実績を CSV で書き出す（1 件ずつ／日ごと・種類ごとの合計。Excel や Google スプレッドシートで開ける）

**そのほか**

- 日記（1日1ページ、気分、その日の予定と実績の振り返り）
- プロジェクト（プロジェクトごとの予定の流れ）
- 予定の種類の設定画面（キーワードで自動分類。例：タイトルに「数学」→ 勉強）
- AI（Claude または Gemini）に話しかけて予定を追加・変更（例：「金曜の15時に歯医者を追加して」）
- Google ドライブを使った、端末間（スマホと PC など）の同期
- スマホのホーム画面に追加でき、オフラインでも開ける
- ほかのアプリからの「共有」でファイルやリンクを受け取り、予定につなげる（受信トレイ）

## 使い始める

### 1. 公開する（GitHub Pages）

1. このリポジトリの Settings → Pages → Source を **GitHub Actions** にする
2. `main` ブランチにこのコードを入れる（入るたびに自動で公開されます）
3. 公開先は `https://<ユーザー名>.github.io/<リポジトリ名>/`

GitHub Pages を無料で使うには、リポジトリが公開（Public）である必要があります。コードが公開されるだけで、手帳の中身（予定・日記・API キー）は端末の中にしかないので外には出ません。

### 2. スマホのホーム画面に追加する

公開先を Chrome で開き、メニューから「ホーム画面に追加」（または「アプリをインストール」）を選びます。追加しておくと、Samsung Notes や Gmail の「共有」の送り先に「手帳」が出るようになります。

### 3. Google カレンダーとつなぐ（最初の1回だけ・約10分）

アプリの「設定 → Google カレンダー連携」にも同じ手順があります。

1. [Google Cloud コンソール](https://console.cloud.google.com/) で新しいプロジェクトを作る
2. 「API とサービス → ライブラリ」で **Google Calendar API** を有効にする
3. 「OAuth 同意画面」を設定する（ユーザーの種類は「外部」。テストユーザーに自分の Google アカウントを追加）
4. 「認証情報 → 認証情報を作成 → OAuth クライアント ID」。種類は「ウェブ アプリケーション」。「承認済みの JavaScript 生成元」に公開先のオリジン（例：`https://<ユーザー名>.github.io`）を追加する
5. できたクライアント ID を、アプリの設定に貼り付けて「Google にログインして同期」

知っておくこと：

- サーバーを持たない作りなので、Google へのログインは約1時間で切れます。切れたら右上の雲のボタンを押すと、もう一度つながります
- Google に送るのは、題名・日時・場所・メモだけです。リンクや持ち物などの書き足した情報は端末の中にだけ置きます
- Google 側で予定が消えても、手帳で情報を書き足してあった予定は消さずに「手帳（この端末）」の予定として残します

### 4. 端末間で同期する（任意）

スマホと PC など、複数の端末で同じ手帳を使えます。手帳の中身は Google ドライブの「このアプリ専用の見えない場所（appDataFolder）」に保存され、ドライブの画面には出ません。Google アカウントの無料の容量を使います。

1. [Google Cloud の Google Drive API のページ](https://console.cloud.google.com/apis/library/drive.googleapis.com)で、カレンダー連携に使ったプロジェクトの Drive API を有効にする
2. 手帳の「設定 → Google カレンダー連携 → デバイス間の同期」で「ドライブで同期する」をオンにし、ログインの画面でドライブへのアクセスも許可する
3. ほかの端末でも、同じクライアント ID と同じ Google アカウントで同じようにオンにする

同期のしかた：

- データを変えると数秒後に自動で同期し、アプリを開いたときにほかの端末の変更を受け取る
- 2 台で同じものを直したときは、あとから直したほうが残る。消したものは、ほかの端末からも消える
- 同期を始める前に 2 台がそれぞれ取り込んでいた Google カレンダーの同じ予定は、1 つにまとめる（書き足した情報はどちらも残す）
- 5MB より大きいファイルと、API キーなどの設定は同期しない

### 5. AI に話しかけて使う（任意）

「設定 → AIアシスタント」で、使う AI を **Claude** か **Gemini** から選び、その API キーを入れます。キーはこの端末の中にだけ保存され、ブラウザから選んだ AI の API を直接呼びます。自分だけが使う端末で使ってください。

| | Claude | Gemini |
|---|---|---|
| API キーを作る場所 | [Anthropic Console](https://console.anthropic.com/settings/keys) | [Google AI Studio](https://aistudio.google.com/apikey) |
| 料金 | 使った分だけ（前払いのチャージ式） | 無料の枠あり（1分・1日あたりの回数に上限） |
| 送った内容の扱い | AI の学習に使われない | 無料の枠では、サービスの改善に使われることがある |

Gemini の無料の枠の条件は変わることがあります。使う前に、Google の[料金](https://ai.google.dev/gemini-api/docs/pricing)と[利用規約](https://ai.google.dev/gemini-api/terms)のページで確かめてください。AI に送られるのは、頼んだ文章と、それに答えるために読んだ予定・実績・日記の内容です。

Gemini のモデルの名前は入れ替わりが早いので、設定画面の「モデルの一覧を取得」で、いま使えるものから選べるようにしてあります。

## データについて（大事）

- 予定・実績・日記・ファイルは、まず**開いているブラウザの中**に保存されます。「ドライブで同期する」をオンにすると、Google ドライブを通して、ほかの端末とも同じ内容になります
- ブラウザのデータを消すと手帳のデータも消えます。「設定 → データ → バックアップを保存」で、ときどきファイルに書き出しておくと安心です。機種変更のときは、新しい端末で「バックアップから復元」します
- バックアップに API キーや Google のログイン情報は含まれません

## 開発

```bash
npm install
npm run dev        # 開発用サーバー（http://localhost:5173）
npm test           # 計算部分のテスト
npm run e2e        # 画面を実際に操作するテスト（Playwright が必要）
npm run build      # 本番用にビルド（dist/）
```

`npm run e2e` は Google・Claude・Gemini の API を偽物に差し替えて動かすので、本物には何も送りません。

### 構成

```
src/
  lib/          データと計算（画面に依存しない）
    types.ts      データの形
    db.ts         端末内のデータベース（IndexedDB）
    store.ts      データを書き換える操作はすべてここ
    date.ts       日付の計算と表示
    resolve.ts    種類の自動判定、月表示に出すかの判定
    layout.ts     重なった予定の配置、月表示の段の割り振り
    stats.ts      時間の使い方の集計
    csv.ts        実績の CSV 書き出し
    google.ts     Google カレンダーとの同期（ログインもここ）
    drive.ts      Google ドライブを使った端末間の同期
    syncmerge.ts  端末間の同期で、2 つの状態を 1 つにまとめる計算
    sync-hooks.ts データの変更時刻と削除を自動で記録する見張り
    assistant.ts  AI との会話と、AI が使う道具（Claude・Gemini 共通）
    claude.ts     Claude の呼び出し
    gemini.ts     Gemini の呼び出し
    share.ts      「共有」で届いたものの取り込み
  components/   画面の部品
  views/        各画面（月・週・一日・予定・時間の使い方・日記・プロジェクト・設定）
  styles/       見た目（tokens.css に色と寸法の決まり）
public/sw.js    オフライン対応と「共有」の受け取り
tests/          計算部分のテスト
e2e/            画面を操作するテスト
```

## これから育てる候補

- 予定をドラッグして時刻を動かす（今は実績だけドラッグできる）
- 通知（締切や持ち物のリマインド）
- 月・週の時間の使い方の比較（先週との差、目標時間）
